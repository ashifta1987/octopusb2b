## Interface contract between the two §16 agents (HTTP routes; the infra agent builds them, the UI agent calls them)
All routes require a session with the matching `backups` permission (use getSession + can) unless noted; return JSON `{ ok: true, ... } | { ok: false, error }`.
- `POST /api/backups/trigger` — body {note?}; calls rpc request_backup then dispatches GitHub workflow `backup.yml` (workflow_dispatch, inputs {backup_code, trigger:'manual'}) via GitHub API using env GITHUB_REPO + GITHUB_ACTIONS_TOKEN. If not configured → `{ ok:false, error:'GITHUB_NOT_CONFIGURED', backup_id }` (the row stays queued; UI shows setup notice).
- `POST /api/backups/restore/[id]/verify` — dispatches `restore.yml` with {restore_id, mode:'verify', target:'scratch'}.
- `POST /api/backups/restore/[id]/run` — rpc start_restore then dispatches `restore.yml` {restore_id, mode:'run', target}. For target production the workflow itself turns maintenance on/off.
- `GET  /api/backups/[id]/download` — permission backups:download + mfa_recent(); returns `{ ok, url, expires_in: 600 }` (S3 SigV4 presigned GET for the manifest/archive at backups.location) and writes audit_log via rpc? (use service role insert into audit_log). If off-site not configured → error 'OFFSITE_NOT_CONFIGURED'.
- `POST /api/backups/offsite/test` — admin; tests the S3-compatible bucket (HEAD/PUT a small test object) using env BACKUP_S3_*; updates backup_settings.offsite.last_test_at/ok.
- `POST /api/backups/status` — NO session: HMAC-signed callback from workflows (header `Octopus-Signature`, verifySignature with env BACKUP_CALLBACK_SECRET); body {type:'backup'|'restore', ...} → backup_report / restore_report.
- `POST /api/exports/[id]/run` — permission backups:export; builds the export now (worker function) and returns `{ ok, status }`.
- `GET  /api/exports/[id]/download` — permission backups:export; `{ ok, url }` signed URL (10 min) from bucket `exports`, audited.
- `GET  /api/cron/backup-monitor` (CRON_SECRET) — alerts (email via getEmail to backup_settings.alert_email + integration_logs) when backup_overdue(); also runs queued monthly exports and the monthly drill trigger.
