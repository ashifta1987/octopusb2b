## Contract between the two §17 agents
- Routes (auth-flow agent builds): `/staff/login` (step 1), `/staff/verify?next=` (step 2: enrol or challenge; also used for STEP-UP — when a page/action gets STEP_UP_REQUIRED, redirect to `/staff/verify?next=<current path>&reason=step_up`), `/staff/workspace` (step 3), `/staff/set-password` (invite + reset landing), `/staff/forgot`, `/staff/account` (profile, change password, 2FA devices + regenerate backup codes, sign out, active sessions "sign out everywhere").
- Exported helpers (auth-flow agent builds in `lib/staff/`): `lib/staff/workspaces.ts` → `WORKSPACES` + `workspacesFor(session)`; `lib/staff/step-up.ts` → `isStepUpError(err)` (matches STEP_UP_REQUIRED / row-level security on user_roles|role_permissions / MFA_REQUIRED) and `stepUpRedirect(path)` → `/staff/verify?next=…&reason=step_up`; `lib/staff/request-meta.ts` → `getRequestMeta()` {ip, ua} from headers.
- Admin agent uses those in admin pages; until they exist, it may import them (they will be created) — coordinate by exact names above.
