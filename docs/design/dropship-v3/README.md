# Octopus Dropship - UI/UX design package

Live design canvas: https://claude.ai/artifact/VaAA7Bj2CKNsa1UEGudHjs

The `design/` folder holds one HTML file per screen (51 screens). Open any file in a browser to see the screen. Give Antigravity this folder and tell it to match each screen when building it.

## Design rules
- Font: Inter. No emoji.
- Navy #1A174A, button blue #2A6FD1, logo blue #2F7BE0, success teal #0B7A75, page background #F4F6FA
- Status badges: ok, warn, bad, info, neutral
- Touch targets at least 44px. Merchant screens never show supplier names.
- Sample data in the screens is for design only.
- Placeholders in square brackets (for example [HS CODE], [RATE]) need real data before launch.

Read SPEC.md first.
