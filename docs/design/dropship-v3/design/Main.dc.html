Octopus Dropship: app structure

Merchant app, staff panel, core flows and build notes

Merchant app

What your customers see (white-label)

  • Dashboard
    Setup checklist, KPIs, alerts, plan usage
  • Find products
    Catalog, filters, product detail, add to import list
  • Import list
    Edit, price, bulk actions, push to store; tabs: Pushed, Failed
  • Orders
    All channels in one list, order detail, pay and fulfil, tracking
  • Pricing & sync
    Pricing rules, stock and price auto-sync, sync log
  • Stores
    Connect Shopify, WooCommerce, Wix, Amazon, TikTok Shop, eBay
  • Wallet, Reports
    Top-up and ledger; profit by product, store and period
  • Plan & billing
    Starter $49, Growth $149, Custom $299, invoices
  • Settings, Support
    Profile, team, notifications, branding; help, tickets
  • Auth and onboarding
    Sign up, log in, 4-step first-run wizard

Staff admin panel

Internal only: supplier names are visible here

  • Suppliers
    DSers / Alibaba link, own warehouse, other suppliers
  • Catalog manager
    Approve products, set landed cost, hide source from merchants
  • Warehouse (China)
    Stock in/out, packing queue, carrier labels
  • Fulfilment queue
    Paid orders, assign source, tracking numbers (YunExpress, 4PX)
  • Merchants
    Accounts, stores, wallet top-ups, support notes
  • Plans & limits
    Edit plan limits and feature flags
  • System health
    Sync jobs, failed pushes, webhook log
  • Support desk
    Merchant tickets, refunds and returns approval

Core flows

The three journeys to get right

  • 1. Onboard
    Sign up, connect Shopify, set a pricing rule, first push
  • 2. Import and push
    Find, add to list, price, push as draft, review in Shopify
  • 3. Order to delivery
    Shopify order arrives, wallet pay, source assigned, shipped, tracking sent back to Shopify
  • 4. Keep in sync
    Cost or stock change, rule recalculates, store updates, alert if needed

Build notes for Antigravity

Suggested routes and Supabase tables

  • React routes
    /dashboard, /catalog, /catalog/:id, /import, /orders, /orders/:id, /pricing, /stores, /billing, /admin/*
  • Core tables
    merchants, stores, products, variants, import_items, pricing_rules, orders, order_items, shipments, sync_logs, plans, wallet_ledger
  • Server functions
    Shopify token refresh, push-product, order webhook, stock and price sync job
  • Rules
    Row Level Security by merchant_id; supplier fields never sent to merchant views
