Per-connection settings

Every connection has the same settings page, so nothing is hard-coded.
  • Credentials, stored as server-side secrets
  • Sandbox or production mode
  • Field mapping (SKU, HS code, weight, address fields)
  • Which categories, suppliers or countries it applies to
  • Price markup or shipping fee rules in USD
  • Default service and fallback connection
  • Sync log with retry for failed calls
