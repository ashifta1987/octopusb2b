Quick start

1. Get an access token (valid 1 hour)
curl -X POST https://sandbox-api.octopusb2b.com/v1/oauth/token \
  -d grant_type=client_credentials \
  -d client_id=oct_test_ci_7Hk2Qp9xLm4Rv8 \
  -d client_secret=YOUR_CLIENT_SECRET
2. Call the API with the token
curl https://sandbox-api.octopusb2b.com/v1/products?category=fasteners&limit=50 \
  -H "Authorization: Bearer ACCESS_TOKEN"
