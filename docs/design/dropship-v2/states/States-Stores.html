States: store connection

Every state of connecting, renewing and disconnecting a Shopify store.

State Disconnect

Confirmation dialog

Disconnect anna-home.myshopify.com?

  • Stock at the Octopus Dropship location is set to 0 first, so nothing more can be sold.
  • Orders already paid are still shipped. Orders and invoices stay in your account.
  • You can reconnect any time.
State Before uninstalling (inside Shopify)

Shown in the embedded app

Use Disconnect before you uninstall.

If you uninstall the app directly, Octopus products can stay on sale and those orders can’t be fulfilled.

State Access needs renewing

Refresh failed

We couldn’t renew access to your store.

Nothing is lost. Reconnect to resume orders and stock updates.

State Review sandbox

Review sandbox – no real orders.

Orders stop at 'Waiting for wallet top-up'. Wallet top-ups are turned off for this account.

BUILD NOTES FOR ANTIGRAVITY
Route: /account/dropship/stores, /shopify
Data: store_connections, store_credentials (server only), shopify webhooks, is_review_sandbox
  • Disconnect: stock to 0 at our location → optional hide listings → revoke and delete credentials → keep orders and invoices.
  • Late orders for a disconnected store are recorded and never charged.
  • Review sandbox is set by admin only; top-ups blocked.
