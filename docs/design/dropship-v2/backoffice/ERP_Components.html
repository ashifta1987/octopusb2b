  • Numbers right-aligned with tabular figures; money always shows currency in the header.
  • Sort (click header), resize and reorder columns, show/hide columns, saved views per user, density toggle.
  • Row checkbox → bulk action bar; right-click or ⋯ → context menu; double-click or Enter → open in a tab.
  • Virtualised for long lists; totals for the selection in the bulk bar; export CSV/XLSX respects filters.
