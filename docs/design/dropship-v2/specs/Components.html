Accessibility rules

  • Text contrast at least 4.5:1; muted text #5B6478 passes on white and on #F4F6F9
  • Every control is a real button, link or input with a label
  • Selected chips use aria-pressed; current page uses aria-current
  • Keyboard focus ring: 2 px white + 2 px blue
  • Colour never carries meaning alone: every badge has words
  • Errors name the field and say how to fix it
