BUILD NOTES FOR ANTIGRAVITY
Route: /shop/checkout
Data: cart (Buy now part), addresses, shipping rate cards, wallet_available(), payment provider session, proformas, orders
  • Checkout needs a verified company (KYC); otherwise it shows the 'Verify your company' state.
  • Placing the order: one checkout payment, then one order per type (OCT-SMP-, OCT-STK-, pool hold, OCT-MMB-, SRV-) linked by a checkout number.
  • Card: redirect or embedded fields from the payment provider; we store only the provider's payment reference. Never card numbers.
  • Bank transfer: issue PF- proforma; orders wait in 'Awaiting payment'; stock held 3 days, then released.
  • Payment protection: money held in the escrow ledger; released per order after the QC passes.
  • Totals are recalculated on the server at 'Place order'; if anything changed, show the change and ask again.
  • Shipping prices come from rate cards; 'Quoted at order' when no rate exists.
