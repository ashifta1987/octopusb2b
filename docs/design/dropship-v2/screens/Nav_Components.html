5 · Segmented control

Use for: 2–3 options that switch the view of the same data.

Specs
  • 40 px tall inside a grey track; selected segment white with a shadow.
  • Labels stay short (1–2 words); icons optional.
Keyboard and screen readers
  • Buttons with aria-pressed in a labelled group (or radio group).
  • Arrow keys move between segments.

6 · Card tabs

Use for: numbers that are also filters, at the top of Orders, Requests and Wallet.

Specs
  • Min 96 px tall; number 26 px bold; the small line explains it.
  • Selected: 2 px blue border and light blue fill.
  • 4 per row on desktop; 2 per row on phones.
Keyboard and screen readers
  • Buttons with aria-pressed; the label reads e.g. 'Waiting for you, 3 orders'.
  • Selecting one updates the list below and the URL.

BUILD NOTES FOR ANTIGRAVITY
Route: components/navigation/*
Data: —
  • Build each pattern once as a component (Tabs, FilterPills, Segmented, CardTabs, Stepper, Breadcrumbs, Sidebar, BottomNav, SectionBar, MegaMenu) and reuse it everywhere.
  • Tabs and filters write to the URL (?tab=, ?status=, ?service=) and read from it on load.
  • Tab panels load when first opened (lazy) and keep their state when you switch back (persistent).
  • Touch targets ≥ 44 px; the focus ring is the 3 px amber outline used here.
