  2. 2Click 'Continue with Google'The shop tab (tab 2) opens and shows Google’s sign-in. The introduction tab stays as it is.
  3. 3Choose a Google accountGoogle sends them back to tab 2, signed in.
  4. 4First time only: set up the companyCompany name, country, phone and what they want to do. Takes under a minute.

Reuse, don’t duplicate

'My account ↗' and 'Browse products ↗' always go to the same named tab. If that tab was closed, a new one opens.

Sign out everywhere

Signing out in any tab signs out all tabs; the others show 'You signed out' with a Sign in button.

Phones

On phones every link opens in the same tab, and the bottom bar switches between Shop and My account.

Returning visitors

If already signed in, 'Continue with Google' on the introduction page goes straight to the shop tab.

New: sign in with Google and the three tabs
  1. The introduction page only explains the application; signing in opens the shop in its own tab.
  2. Google sign-in, a one-minute company setup the first time, then the shop.
  3. 'My account ↗' and 'Browse products ↗' switch between the two signed-in tabs instead of opening copies.
BUILD NOTES FOR ANTIGRAVITY
Route: /, /login, /auth/callback, /welcome/setup, /shop, /account
Data: Supabase Auth (Google provider), profiles, companies, company_members
  • Introduction page: 'Continue with Google' and 'Sign in' are links with target="octopus-shop" to /login?next=/shop. The click opens tab 2 directly, so no pop-up blocker is involved.
  • /login calls supabase.auth.signInWithOAuth({provider:'google', options:{redirectTo: origin + '/auth/callback?next=/shop'}}). The callback exchanges the code, then: no company → /welcome/setup; else → next.
  • Same-site links between our own tabs use named targets without rel=noopener, so the browser can find and reuse the existing tab. External links keep target=_blank rel=noopener.
  • Shop header 'My account ↗' → /account with target="octopus-account"; panel 'Browse products ↗' → /shop with target="octopus-shop".
  • Sign-out in one tab: broadcast with BroadcastChannel('octopus-auth'); other tabs show the signed-out overlay. The introduction tab listens too and swaps Sign in for 'Go to my shop ↗'.
  • An email that already has an account signs in to that same account (identity linking on a verified email). One login per person; team members are invited from My account › Team.
  • Phones (under 768 px): no target attribute; same-tab navigation.
