BUILD NOTES FOR ANTIGRAVITY
Route: all routes, under 768 px
Data: —
  • Bottom bar: 5 items max, labels always visible, badges for counts.
  • 'More' and 'Categories' open bottom sheets (drag handle, close button, Esc/back closes).
  • Filters open a full-screen sheet with Clear and 'Show N results'.
  • The Android/iOS Back button closes the open sheet first, then goes back a page.
  • Focus is trapped inside open sheets and returns to the button that opened them.
