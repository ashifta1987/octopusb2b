Which navigation goes where

PatternWhereWhy
Header menu + mega menuIntroduction websiteFew pages; visitors browse
Search + section bar (+ More ▾ overflow)Shop, desktopMany sections; search first
Sticky pill jump barShop main pageSix sections on one long page
Sidebar (vertical) + collapsed iconsMy account, desktopMany back-office pages, always visible
Underline tabsInside one record: product, request, order, projectSwitch parts of the same page
Pill filters with countsEvery listFilter without leaving the page
Card tabsTop of Orders, Requests, WalletNumbers that are also filters
Segmented control2–3 options: Sea/Air, List/Board, Month/YearQuick view switch
StepperOrders, pools, Turnkey, checkout, verificationShows where a process is
BreadcrumbsEvery page below level 1Way back up
Bottom navigationPhonesThumb reach; 5 items max
New: one navigation system for Octopus B2B
  1. One tab style per job (not per service), the same in every service including Dropshipping.
  2. Every page has a URL; tabs and filters are kept in the URL so links can be shared and Back works.
  3. Cross-tab links: 'Continue with Google' → Shop tab; 'My account ↗' → My account tab; 'Browse products ↗' → Shop tab.
